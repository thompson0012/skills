# 評測閉環

沒有測試集的 prompt 等於沒有完成。Standard 以上交付時附簡版建議，Full 附完整方案。

1. **建立測試集**：20–50 個真實案例起步，含常見、邊界、對抗（含注入）案例。
2. **定義評分**：規則檢查 + 量表（rubric）+ LLM-as-judge；judge 需人工抽樣校準。
3. **一次只改一處**，比較前後版本。
4. **版本控管**：像程式碼一樣有 diff、changelog、回歸測試。
5. **線上監控**：失敗樣本回流測試集。
6. **換模型、換資料、換需求都重跑評測**，不假設 prompt 可直接移植。
