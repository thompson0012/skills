# 場景調整

| 場景 | 關鍵做法 |
|---|---|
| RAG／知識問答 | 要求只依據提供資料、附引文、找不到就說不知道。檢索品質比措辭更重要，先檢查檢索結果再調 prompt |
| Agent／程式開發 | 提供程式庫規範、測試指令、完成定義；要求先讀後改、改後跑測試；小步提交 |
| 資料抽取／分類 | 結構化輸出 + schema 驗證 + 含邊界案例的範例 + 缺值規則 |
| 寫作／創意 | 提供受眾、語氣樣本、禁忌；分「發散 → 收斂 → 潤飾」多輪 |
| 分析／決策支援 | 要求列假設、比較方案、敏感度、反方觀點；數字用工具計算 |
| 多模態 | 明確指出看哪裡、要提取什麼；圖文並置；要求標示看不清楚的部分 |
| 企業部署 | system prompt 分層治理、權限、稽核紀錄、PII 處理、合規 |
